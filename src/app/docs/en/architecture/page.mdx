# Architecture & Technical Stack

Istqrar leverages modern frontend patterns built around Next.js 16 App Router, React 19, and full bi-directional internationalization.

---

## Routing & Localization Strategy

1. **Locale Prefixing**: Routes under `[locale]` receive either `ar` or `en` (e.g. `/ar/dashboard`, `/en/dashboard`).
2. **Direction Control**: The `DirectionProvider` in `src/app/[locale]/layout.tsx` dynamically sets `dir="rtl"` for Arabic and `dir="ltr"` for English, loading the `DIN Next LT Arabic` font family.
3. **Docs Isolation**: The documentation system lives at `/docs` outside of `[locale]`. The middleware in `src/proxy.ts` automatically ignores `/docs` to prevent accidental redirection loops.

---

## State Management

Global client state is managed via **Redux Toolkit**:

- **Store Provider**: Wrapped inside `src/providers/store-providers.tsx`.
- **Role & Auth State**: Managed through dedicated slices with authentication tokens persisted via secure cookies.
- **Table Virtualization**: Powered by `@tanstack/react-virtual` and `@tanstack/react-table` for fluid rendering of extensive inspection datasets.
