# نظرة عامة على منصة استقرار

مرحباً بك في التوثيق الفني لمنصة **استقرار**.

منصة استقرار هي نظام سحابي متكامل لإدارة الامتثال، التفتيش، والتدقيق الميداني على الجودة، صُممت خصيصاً لأتمتة عمليات التدقيق على المنشآت والشركات وسلاسل الفروع والمفتشين الميدانيين.

---

## أبرز المميزات التقنية

- **Next.js 16 (App Router)**: مدعوم بإصدار React 19 مع مجمع React Compiler لتحقيق أعلى أداء في العرض والتنقل.
- **دعم كامل للغتين (i18n)**: واجهات عربية تدعم الاتجاه من اليمين لليسار (RTL) مع خط `DIN Next LT Arabic`، وواجهات إنجليزية (LTR) عبر `next-intl`.
- **نظام تحكّم بالصلاحيات (RBAC)**: إدارة صلاحيات دقيقة لأربعة أدوار رئيسية: `super_admin`، `auditor`، `company_admin`، و `branch_manager`.
- **محرك تفتيش متقدم**: قوائم تحقق ديناميكية مع معايير ترجيحية وشروط تشعب ذكية، وتحليل مدعوم بالذكاء الاصطناعي لتقارير الزيارات.
- **بنية برمجية مرنة**: إدارة حالة مركزية عبر Redux Toolkit، وتنسيقات عبر Tailwind CSS v4، ومكونات مبنية على Radix UI.

---

## الهيكل التنظيمي للمنصة

```
إدارة النظام (Super Admin)
 └── الشركات والمؤسسات (Companies)
      └── الفروع الميدانية (Branches)
           ├── زيارات التدقيق والتقييم المجدولة
           │    ├── استبيانات ديناميكية ومعايير تقييم
           │    ├── تحليل تقارير مدعوم بالذكاء الاصطناعي
           │    └── تذاكر وإجراءات تصحيحية للملاحظات
           └── المفتشون الميدانيون ومديرو الفروع
```

---

## مصفوفة الأدوار والصلاحيات

| الدور | نطاق الوصول | المسؤوليات الرئيسية |
| :--- | :--- | :--- |
| **المشرف العام (Super Admin)** | كامل النظام | إدارة إعدادات المنصة، باقات الاشتراك، إضافة الشركات، والتحليلات العامة. |
| **المدقق الميداني (Auditor)** | الزيارات المسندة | تنفيذ الزيارات الميدانية، إدخال نتائج الاستبيانات، إرفاق الصور والأدلة، ورفع التقارير. |
| **مسؤول الشركة (Company Admin)** | نطاق شركته | متابعة أداء الفروع، تعيين المفتشين، مراقبة مؤشرات الامتثال، ومتابعة إغلاق التذاكر. |
| **مدير الفرع (Branch Manager)** | نطاق فرعه | استعراض نتائج الزيارات، متابعة التقييمات، وتطبيق الإجراءات التصحيحية للتذاكر المفتوحة. |
