تعتمد منصة استقرار على بنية تقنية متطورة تجمع بين أحدث معايير Next.js 16 App Router وإدارة الحالة الفعالة.

```
│                      Next.js 16                        │

└────────────────────────────────────────────────────────┘
```

## آلية التعريب والاتجاه (RTL / LTR)

1. **دعم اللغة العربية الأساسي**: يستخدم النظام خط `DIN Next LT Arabic` مع تفعيل كامل للاتجاه من اليمين إلى اليسار (`dir="rtl"`).
2. **عزل التوثيق**: تم استثناء مسار التوثيق `/docs` في ملف `src/proxy.ts` لتجنب إعادة التوجيه القسري، مع دعم التبديل بين النسخة العربية `/docs/ar` والإنجليزية `/docs` بضغطة زر.
3. **إدارة الحالة المركزية**: تتولى Redux Toolkit إدارة بيانات المستخدم النشط وتفاصيل الجلسة، بينما تُدار الجداول الكبيرة عبر تقنية المحاكاة الافتراضية Virtualization لضمان سرعة الاستجابة.
