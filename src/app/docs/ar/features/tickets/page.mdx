# نظام التذاكر والملاحظات

يهدف نظام التذاكر إلى تحويل الملاحظات والمخالفات المكتشفة أثناء التدقيق إلى خطة عمل علاجية قابلة للقياس والتوثيق.

---

## مسار معالجة التذكرة

```
[ رصد مخالفة أثناء الزيارة ]
             │
             ▼
      [ فتح تذكرة تصحيحية ]
             │
      ┌──────┴──────┐
      ▼             ▼
[ منخفضة / متوسطة ]   [ حرجة وعاجلة ]
(مهلة 7 أيام)         (مهلة 24 ساعة)
      │             │
      └──────┬──────┘
             ▼
    [ معالجة من قبل الفرع ]
             │
             ▼
   [ رفع وإثبات دليل المعالجة ]
             │
             ▼
    [ مراجعة المدقق والإغلاق ]
```

---

## بيانات وحقول التذكرة

| الحقل | الوصف |
| :--- | :--- |
| **عنوان ووصف المخالفة** | شرح واضح للبند غير المطابق وموقعه داخل الفرع. |
| **مرجع الزيارة** | رابط مباشر يربط التذكرة برقم الزيارة والمعيار التابع له. |
| **مستوى الأهمية** | `منخفضة`، `متوسطة`، `عالية`، أو `حرجة`. |
| **المسؤول عن المعالجة** | مدير الفرع أو مشرف الصيانة المكلّف بالإصلاح. |
| **دليل المعالجة** | صورة فوتوغرافية أو فاتورة أو تقرير يؤكد اكتمال المعالجة. |
| **الحالة** | `جديدة`، `قيد المعالجة`، `قيد المراجعة`، `تم الحل`، `مغلقة`. |
