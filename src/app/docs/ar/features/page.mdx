# دليل المميزات والوحدات

تنقسم منصة استقرار إلى مجموعة من الوحدات التشغيلية المترابطة التي تغطي دورة حياة التدقيق بالكامل.

---

## الوحدات الرئيسية

### [الزيارات الميدانية والتدقيق](/docs/ar/features/visits)
المحرك الأساسي للعمليات الميدانية: جدولة الزيارات، استيفاء استبيانات التفتيش، رفع الأدلة والصور، التحليل الذكي عبر الذكاء الاصطناعي، وتوليد التقارير المعتمدة.

### [الشركات والفروع](/docs/ar/features/companies-and-branches)
إدارة الهيكل المؤسسي متعدد المستويات: تسجيل الشركات، ربط الفروع الجغرافية بالخرائط، وتعيين المفتشين والمديرين لكل فرع.

### [قوائم التحقق والمعايير](/docs/ar/features/checklists-and-criteria)
بناء وتخصيص نماذج التفتيش: تقسيم القوائم إلى بنود وأقسام، تحديد الأوزان النسبية لكل معيار، وضبط شروط التشعب الديناميكية.

### [نظام التذاكر والملاحظات](/docs/ar/features/tickets)
متابعة إغلاق المخالفات الناتجة عن الزيارات الميدانية وتتبع معالجتها ضمن اتفاقيات مستوى الخدمة (SLA).
